# Netflix Dashboard Analysis 🎬📊

## Overview
This project analyzes the Netflix catalog of movies and TV shows using Python and interactive dashboards.  
The goal is to uncover insights such as genre distribution, release trends, ratings, and country contributions.

## Dataset
- Source: [Netflix Movies and TV Shows dataset on Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)
- Contains information about titles, type (Movie/TV Show), release year, rating, duration, and country.

## Features
- 📈 **Overview Page**: Total titles, movies vs TV shows, yearly release trend  
- 🎭 **Genre Analysis**: Top genres, word cloud visualization  
- 🌍 **Country Insights**: Map visualization of content by country  
- 🔢 **Ratings & Duration**: Distribution of ratings, average movie duration  
- 🔍 **Interactive Filters**: Search by genre, country, release year  

## Tech Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Seaborn , matplotlib  for dashboard
- Jupyter Notebook for exploratory analysis

## How to Run
This project analyzes the Netflix titles dataset using Python.
It includes:
- Jupyter Notebook (`netflix.ipynb`) with full analysis
- Dataset (`netflix_titles.csv`)
- Plots (saved as PNGs in the `images/` folder)

1. Clone the repo
2. Open `netflix.ipynb` in Jupyter Notebook or VS Code
3. Run cells to reproduce analysis
